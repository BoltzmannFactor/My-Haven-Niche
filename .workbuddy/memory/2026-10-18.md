**架构决定**：内容只来自 `content/shuoshuo/*.md`，网页发布不再是「写数据库」，而是经 GitHub Contents API 往仓库提交一个 md 文件。一次提交同时触发 Vercel 重建（访客看到）和落进仓库（Obsidian pull 拉到）——「发布」和「写进 Obsidian」是同一件事，不需要双向同步逻辑。

**改动**

- 新增 `app/lib/auth.ts`：口令 SHA-256 后 `timingSafeEqual` 恒定时间比对；会话 token 为 `<过期时间戳>.<HMAC-SHA256>`，服务端无状态
- 新增 `app/api/session/route.ts`：GET 查登录态 / POST 换 Cookie / DELETE 退出；HttpOnly + SameSite=Lax + 生产 Secure；登录限流 5 次/分（内存 Map，超 1000 条清过期项）
- 新增 `app/api/shuoshuo/route.ts`：鉴权后 PUT 到 `api.github.com/repos/{repo}/contents/content/shuoshuo/{file}`；文件名 `YYYY-MM-DD-HHmmss.md`、frontmatter date `YYYY-MM-DDTHH:mm:ss+08:00`，都用 `Intl.DateTimeFormat` 按 Asia/Shanghai 生成（避免 UTC 把晚上发的说说记成前一天）；发布限流 10 条/分
- 改造 `app/components/ShuoshuoBoard.tsx`：props 改为 `initial` + `canPost`；未授权显示口令框，授权后显示发布框 + 退出；发布成功提示「已写进 Obsidian，约一分钟后全站可见」并附 GitHub 文件链接

- 删除 `app/lib/cache.ts` 与 `app/api/data/`（Redis 那套整套移除）
